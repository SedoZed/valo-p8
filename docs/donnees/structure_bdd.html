Cartographie des modèles de ressource

Cartographie de la base de données à partir des ressources templates principaux

Auteur·rice

Cédric BOUCLY

Date de publication

1 novembre 2026

Mots clés

Omeka S, documentation, structure de données, métadonnées, ontologies

Ce document décrit la structure telle que la déclarent les modèles de ressources (resource template) de l’instance Omeka S, dédié au projet de cartographie du SVR de l’Université Paris 8, croisée avec les propriétés et les resource_classes`. Il ne dit rien des données réellement saisies.

Mode d’emploi

Types de données

Notation Sens dans Omeka S
str Chaine de caractères attendue (texte, date, mail,). Faire attention à bien vérifier si une structure de saisi est attendue.
resource Lien vers une ressource interne (item, collection ou média) de la base
uri Lien vers une redirection externe comme idRef, scanR, etc

*Les annotations sont mises de côté, et il sera spécifié si une annotation peut être attendue à un moment donné.

Conditions d’écriture

  • Cible attendue : pour un lien, le modèle (ex. T3), la classe ou la collection vers lesquels la valeur doit pointer.
  • Structure attendue : pour un texte, le format à respecter (ex. AAAA-MM-JJ, « 14 chiffres »).
  • Les cellules _à compléter_ sont à remplir. Les mentions Piste : dans Notes sont des hypothèses, à valider ou supprimer.

Graphe des liens

Chaque flèche correspond à une propriété de type resource. Les cibles inconnues apparaissent en nœuds orange ?.

Pour compléter : remplace le nœud ? par l’identifiant du modèle cible. Par exemple, T4 -->|"valo:axeRech"| q4c(("?")):::todo devient T4 -->|"valo:axeRech"| T3. Si la cible est une classe sans modèle, crée un nœud, par exemple C_CNU["valo:DomaineCNU"]:::cls.

AstuceNote

La liste ci-dessus détaille le contenu d’un item “enseignant-chercheur” AVANT un quelconque import via le module scanR. Les ajouts de ce dernier post-extraction sont détaillés à la toute fin.

AstuceNote

Les champs “Objet de recherche”, “Axe de recherche”, “Mots-clefs” et “Expertises revendiquées” doivent correspondre à ce qui est écrit sur le dernier rapport HCERES du laboratoire, à la lettre près (sauf séparateurs comme “;”). Autrement, en cas de changement, demander la validation du/des DU(s).
